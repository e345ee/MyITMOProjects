# Discrete Mathematics

![Discrete Mathematics](media/discrete.gif)

Materials for the first-year Discrete Mathematics course.

The directory contains homework assignments for two semesters and a course
project. Main topics include logic, sets, relations, graphs, combinatorics,
Boolean functions, and other fundamental areas of discrete mathematics.
