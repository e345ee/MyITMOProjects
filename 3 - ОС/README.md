# Операционные системы

![Операционные системы](media/os.gif)

Материалы по дисциплине «Операционные системы» за 3 курс.

## Лабораторные

- `ass_1-3` - серия лабораторных на учебной Unix-like ОС в стиле `xv6`:
  доработка ядра, системные вызовы, процессы, планирование, сигналы,
  виртуальная память, lazy allocation, copy-on-write и пользовательские тесты.
- `ass_4` - виртуальная файловая система `VTFS`: реализация backend-ов в C,
  HTTP-взаимодействие и Java-сервер для работы с файловым хранилищем.
