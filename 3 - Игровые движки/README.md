# Игровые движки

Материалы по дисциплине «Игровые движки» за 3 курс.

Проект выполнен в Unity: VR-приложение с готовой Android-сборкой и
экспортированным Unity Package. Бинарные файлы не дублируются в этом
репозитории, чтобы не раздувать историю Git.
